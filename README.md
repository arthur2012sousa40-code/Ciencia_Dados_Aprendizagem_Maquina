## Unidades

### Unidade I — Big Data

Conceitos de Big Data: volume, velocidade e variedade, e por que dados em escala
exigem infraestrutura e técnicas próprias.

### Unidade II — Análise e Ciência de Dados

Pipeline de Ciência de Dados (problema → coleta → preparação → análise →
interpretação → decisão), análise exploratória e manipulação de dados tabulares
com Pandas.

### Unidade III — Gestão de Projetos

Definição do projeto em dupla com Ramon Guilherme Marques do Nascimento: um livro de
ocorrências digital para condomínios residenciais do DF, a partir da análise do livro
de ocorrências em papel. Minha parte é o sistema web e o painel de indicadores.

### Projeto de Ciência de Dados (A1)

Aplicação das seis fases do CRISP-DM ao livro de ocorrências: validações e KPIs em SQL,
notebook em Python e dashboard.
[![Abrir no Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/arthur2012sousa40-code/Ciencia_Dados_Aprendizagem_Maquina/blob/main/Projeto_DataScience/notebooks/crispdm_livro_ocorrencias.ipynb)
Ver [Projeto_DataScience/README.md](Projeto_DataScience/README.md). A base é simulada até a
transcrição do livro real; o formulário com os moradores, a coleta dos dados e o piloto do
sistema são etapas pendentes.

### Módulo IV — Aprendizado de Máquina

Conceitos, laboratório supervisionado (classificação e regressão), PBLs, revisão,
autoavaliação e aplicação ao projeto.
Ver [Aprendizado_de_Maquina/Aprendizado de máquina/README.md](Aprendizado_de_Maquina/Aprendizado%20de%20m%C3%A1quina/README.md).
